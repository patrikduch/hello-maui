# HelloWorldMaui — .NET MAUI Hello World (Windows desktop)

A clean, ready-to-run **Hello World** Windows desktop app built with **.NET 8 MAUI** (WinUI 3, unpackaged).

---



dotnet workload install maui
dotnet restore
dotnet build -t:Run -f net8.0-windows10.0.19041.0
